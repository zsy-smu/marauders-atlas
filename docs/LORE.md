# 内容依据与边界

本图册有50份地点档案，包括分卷入口和跨图关联条目：校域14份、城堡24份、霍格莫德12份。城堡分为地下、地面层、一至七楼及塔楼，共10组。

## 地点资料

每条地点记录位于 `dist/data.js`，包含地点简介、细节、关联故事、作品或章节、资料链接、坐标和年代规则。资料优先参考七部小说与官方 HarryPotter.com / J.K. Rowling 文章；Harry Potter Lexicon 作为非官方章节索引辅助。

## 重要边界

- 原著地图覆盖霍格沃茨城堡和场地。霍格莫德是补充地方志，不在村内显示人物追踪。
- 原著的人物标记带姓名，网页采用电影式脚印。移动路径是年代示意，不是某个具体时刻的情节回放。
- 建筑形状、坐标、相邻关系和道路比例属于插画重建，原著没有提供统一完整的测绘蓝图。
- 独眼女巫通向蜂蜜公爵地窖，开启词为 Dissendium。
- 打人柳下通道通向尖叫棚屋；离开校域地图边缘后，不显示棚屋内的人物位置。
- 双胞胎介绍过七条出校路线，费尔奇知道其中四条。未详述路线不编造出口。
- 四楼镜后通道在1993—94年已坍塌；更早年代按坍塌前状态作推定示意，不证明1976年可通行。未确认1998年曾修复，不编造出口。
- 阿利安娜肖像后的通道属于1998年情节，不混入1993年。
- 有求必应屋属于原地图盲区，以图外札记展示；密室不作为原图已知房间绘制。
- 原著西塔猫头鹰棚屋与电影后期独立塔楼有区别。
- 桃金娘盥洗室的楼层在早期资料表述中存在差异，此处采用《火焰杯》中级长浴室下三层的二楼关系，并在档案注明。
- 六楼男生盥洗室与《混血王子》第24章的地图情节关联。
