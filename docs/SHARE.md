# 项目介绍与配图

仓库：[zsy-smu / marauders-atlas](https://github.com/zsy-smu/marauders-atlas)。下面是可以自行修改、使用的介绍，没有代发到其他平台。

## 中文介绍

做了一张中文活点地图，用原生 JavaScript 和 SVG 写的。

可以探索校域、城堡和霍格莫德，打开 50 份地点档案，也可以切换三个年代看人物和密道记录。1993—94 年的人物组里有费尔奇；有求必应屋保留了地图盲区；独眼女巫和蜂蜜公爵的档案可以互相跳转。

纸面做成了旧新闻纸和黑白版画的样子。开图时墨迹逐渐显现，人物留下的左右脚印会停在原地，再慢慢磨损消失。三楼和四楼有单独的布局，其余楼层还在完善。

源码、制作记录和资料出处都放在仓库里。欢迎试试，也欢迎指出原著细节或手机上不好用的地方。

## English introduction

I made a Chinese-language interactive Marauder’s Map with vanilla JavaScript and SVG. It has three map volumes, 50 location records and three eras. Look for Filch in the 1993–94 character group, check the Room of Requirement’s map blind spot, or follow linked records from the One-Eyed Witch to Honeydukes.

The map uses aged-paper illustrations, an ink reveal and footprints that stay where they land before wearing away. The third and fourth floors have independent layouts; the remaining floors still use a shared guide layout. Source code, making-of notes and references are available in the repository.
