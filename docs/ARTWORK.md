# 视觉素材与生成提示词

两张地图插画使用内置图像生成工具制作。它们作为底图，通过正片叠底与旧新闻纸纹理融合。文字、建筑热区、密道、楼层与人物足迹由网页单独绘制。

纸纹来自项目提供方的既有项目；书页照片和参考视频未收录。生成结果的地理位置并不完全遵循提示词，网页热区按实际画面重新对齐。建筑与坐标均属于视觉重建。
