# 三楼样板：空间差异与关联线索

2026-10-22。此轮没有新增地点、年代、声音或粒子效果，而是让已有三楼资料更值得探索。

![三楼独立导览样板](images/third-floor.jpg)

## 变化

- 三楼不再使用其他楼层的四格导览平面。它有雕像壁龛、狭长陈列廊、公共横廊与两侧支廊；魔咒课和历史禁区分列下部。
- 独眼女巫以走廊雕像而非独立教室说明。禁区保留 1991—92 年历史札记，不在所选年代放入路威。
- 奖品陈列室附近的挂毯可点击或按 Enter/空格，展开两端对照。相同入口也在两端的地点档案中。
- 独眼女巫与蜂蜜公爵可以在档案中双向翻阅；保留所选年代，清除旧搜索/筛选，避免跳转后目录仍留在不相关的结果里。
- 密道对照留在当前分卷，不再因为查看雕像通道而强制跳回校域总览。霍格莫德继续禁用人物追踪。
- 对照条可按 Escape 收起；手机展开时将标题与楼层签暂时让位给图面。关闭后恢复。系统减少动态效果的既有行为不变。

## 依据与留白

1. [官方蜂蜜公爵条目](https://www.harrypotter.com/fact-file/locations/honeydukes)确认地窖与霍格沃茨三楼雕像后通道的连接。
2. [官方隐秘空间专题](https://www.harrypotter.com/features/the-camouflaged-corners-and-secret-spaces-of-hogwarts)说明奖品陈列室附近的挂毯与魔咒课教室附近的连接。
3. 地点档案继续提供《魔法石》第 9—10 章、《阿兹卡班囚徒》第 10 章等作品线索。

这些依据不确定精确门位、翼廊轮廓、方位、距离或转折。因此本图明确标注：**连接关系有据，平面与曲折为导览重建。** 挂毯捷径不能被解释成两间教室的普通邻门。跨卷按钮是阅读导航，不是可操控人物穿行的游戏机制。

## 工程合同

`art.js` 中的 `thirdPlan` 同时包含房间、门位、可通行矩形和人物往返路径。`MAPART.floor('third', era)` 返回该平面和与房间中心一致的档案热区。`app.js` 保存这个返回值，用 `currentFloorPlan.patrols` 创建人物，不再将三楼动画错误地放回默认走廊。后续四楼也已独立，见 [四楼说明](FOURTH-FLOOR.md)。

`data.js` 中的 `ATLAS.connections` 保存两条关联及其端点 ID，档案按钮和图面对照条使用同一份资料。三楼初次交付时，其余九组尚未独立；当前另有地下、地面层、四楼、五楼、七楼，仍有四组共用原导览布局。

## 检查与范围

- `npm run check`：脚本语法、50 个档案、静态引用、原有动画检查与楼层路线检查。
- 路线检查：三楼初次交付时为 10 个楼层 × 3 个年代、90,252 个路径采样位置；四楼独立后为 92,475 个。每处含左右脚偏移的保守余量；另查热区中心、线索两端与平面选择。
- 浏览器检查：三楼两条关联、跨卷返回、年代保留、村内追踪禁用、对照条收起，以及其他楼层与年代的切换。
- 手机检查是浏览器视口验证，不是实体手机验收；未宣称独立 iOS/Safari 或 Android 兼容认证。
- 此轮检查了 390×844、320×568、375×812、430×932 视口。320×568 的短屏模式保留密道资料边界，并给地图留下 135px 高的可视区域；两端按钮 48px 高，收起按钮 44px。
- 图面内部路线一致性不是原著地理测绘的证明。
