# 墨迹与脚印动画

本轮仅研究 [icochi/The-Marauders-Map](https://github.com/icochi/The-Marauders-Map) 的表现思路：地图渐显、左右脚交错、纹理擦除及随行姓名卷轴。未引入其他地图项目或多人服务。

实现由本项目重新编写；没有复制参考仓库的地图、云纹、脚印精灵图或姓名条素材。

- 地图显隐：SVG 分形噪声生成不规则墨迹，改变 alpha 阈值来显现和收回；完成显现后移除整图遮罩，避免持续过滤大图。
- 足迹：按行进距离离散采样，一枚脚印落下后位置不再改变。左右脚交替，横向间隔沿路径的法线方向计算。
- 消退：八级共享的确定性孔洞遮罩局部侵蚀鞋印，不以整枚透明度下降代替纹理擦除。
- 路径：沿既有示意路径往返，避免到达尽头后突然跳回起点；不声称对应原著某一时刻的真实行动。
- 姓名：原创 SVG 卷轴边框；文字与墨迹色保持现有旧新闻纸风格。
- 资源控制：每个人物使用固定数量的 SVG 印记，不随运行时间累积节点；暂停时人物和旧足迹的年龄一起冻结。
- 无障碍：系统减少动态效果时，跳过墨迹过渡与人物移动，保留静态地图和人物标记。

霍格莫德仍是补充地方志，不显示人物追踪。本轮没有改变地点资料、原著边界或地图插画。
