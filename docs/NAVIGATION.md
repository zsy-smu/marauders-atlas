# 探索回程

地图工具栏的 `↶` 和档案里的「← 上一处」使用同一份历史。按钮的悬停提示会说明返回哪里；没有历史时按钮不可用。键盘可用 Tab 聚焦，再按 Enter 或空格。

## 会记住什么

- 从地点档案、楼层、分卷、年代或密道线索跳走前，保存当前来处。
- 返回时恢复分卷、楼层、年代、所选地点和档案开合状态。
- 恢复地图视野、档案正文滚动、目录滚动、搜索词和筛选；原来打开的手机目录也会重新打开。
- 同样大小的画布恢复原来的 viewBox。窗口大小变化时保留中心和相对于整图的缩放倍率，按新宽高比重算视野，不拉伸插画。

拖动、缩放和滚动本身不增加历史；只关闭档案也不会凭空增加一项。没有“前进”分支，不接管浏览器的前进、后退按钮。

## 不会倒退什么

足迹、密道与暂停开关属于当前偏好，不随回程覆盖。人物动画不倒带，霍格莫德仍不显示村内追踪。如果已关闭密道，回程也不会擅自重新打开密道线索。

历史只存在当前页面内存中，最多保留 20 处，连续完全相同的快照不重复入栈；刷新页面即清空。不上传，也不写入 localStorage 或 sessionStorage。

## 实现

`dist/navigation.js` 只负责有界历史、快照隔离和相机换算。`dist/app.js` 负责在导航前采集界面、返回时还原界面。快照不持有 DOM 节点，也不复制动画对象。

每次导航更新版本号，延迟执行的聚焦动作只在版本仍匹配时生效，避免旧跳转在返回后重新夺走视野。恢复期间暂时关闭面板过渡；档案和目录禁用浏览器滚动锚定，避免重建正文时自动修正已恢复的位置。尺寸变化后的相机重排也保留低倍率下的中心点。

## 验证范围

2026-10-23，使用本地预览和内置浏览器验证：

| 场景 | 结果 |
| --- | --- |
| 校域 → 城堡 → 返回 | 回到校域；历史用尽后按钮不可用 |
| 五楼级长浴室 → 桃金娘 → 返回 | 回到五楼；稳定阅读位置下 viewBox 与正文 scrollTop 一致 |
| 独眼女巫 → 蜂蜜公爵 → 返回 | 分卷、档案正确；村内追踪仍禁用，城堡恢复可用 |
| 镜后线索 1993 → 1976 → 返回 | 恢复 1993 年代、原来的线索面板和视野 |
| 手机搜索「蜂蜜」并筛选密道 → 档案 → 返回 | 目录重新打开，搜索和筛选保留 |
| 手机长目录末项 → 档案 → 返回 | 保留列表滚动，末项仍在可见区域 |
| 档案关闭后切年代 → 返回 | 档案维持关闭，不误开旧记录 |
| 关闭足迹后切年代 → 返回 | 足迹保持关闭 |
| 320×568 → 跳走 → 390×844 → 返回 | 地图中心与缩放倍率保留，画布比例一致 |
| 键盘连续返回 | 正确逐项回程，历史用尽后停止 |

视口覆盖 320×568、390×844 和 1280×720。320 像素宽度下，地图按钮至少 44×44 像素，档案回程按钮 80×48 像素，未见横向溢出。测试期间未捕获 JavaScript 错误。这些是浏览器视口测试，不是 iOS Safari、Android 真机或全部浏览器的兼容性结论。

`npm run check` 还会执行 `scripts/check-navigation.mjs`：检查快照隔离、连续重复抑制、LIFO 顺序、1,000 次访问后的 20 条上限、无历史返回、相同画布精确恢复、四种画布尺寸下的中心/倍率/比例及无持久化存储约束。该脚本是模型检查，不替代上述界面实测。
