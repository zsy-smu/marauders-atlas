# 四楼：书页深处与镜后旧路

2026-10-22。延续三楼样板，四楼采用独立平面，不增加地点档案数量或无依据的新房间。

![四楼导览平面](images/fourth-floor.jpg)

## 空间与识别

图书馆用较大的馆内空间区分后部禁书区、普通书架与阅览桌。禁书区有绳索分隔和教师书面许可提示，阅览区保留禁带食物的内容提示。镜子位于另一处走廊壁龛，通道从镜框后方开始，末端只标“出口未详”，不接到虚构的商店。

**这些是同层资料的导览组织，不证明图书馆与镜子相邻，也不表示两者有秘密连接。** 建筑轮廓、门位、走廊、绳索与书桌位置均为重建。人物仍只沿公共走廊往返，不进入图书馆、禁书区或镜后密道。

## 年代不是通行开关

- 1976：显示坍塌前的较早年代推定，不画碎石；明确提示没有确认该年可以通行。
- 1993—94：显示已知坍塌记录、碎石与阻断符号。
- 1998：沿用已知坍塌记录，未确认该年曾修复，不擅自开放。

推定与坍塌两种线条均不使用流动路线动画。档案内及图面对照条都可切换较早示意与 1993—94；全球年代选择器与对照状态同步。档案内切换后恢复阅读滚动位置和所选按钮焦点；对照条可以 Escape 收起，焦点返回镜子。

## 资料依据

- [官方图书馆条目](https://www.harrypotter.com/fact-file/locations/the-hogwarts-library)：大量藏书、平斯夫人管理及禁止饮食。
- [官方禁书区条目](https://www.harrypotter.com/fact-file/locations/the-restricted-section)：位于馆内后部、用绳索分隔、学生须有教师书面许可。
- 镜后旧路的坍塌记录以《阿兹卡班囚徒》第 10 章为依据；[Harry Potter Lexicon 四楼索引](https://www.hp-lexicon.org/place/hogwarts-school-of-witchcraft-and-wizardry/hogwarts-fourth-floor/)为非官方辅助索引。
- 四楼地点收录继续沿用项目已有的作品线索；没有将官方图书馆页面误说成官方四楼建筑蓝图。

## 检查范围

`npm run check` 检查脚本语法、50 份档案及引用、既有脚印动画、10 个楼层 × 3 个年代共 92,475 个路径采样位置；每个位置还检查双脚偏移的保守余量、是否进入房间。新增检查覆盖四楼热区中心、镜子入口、年代推定与碎石状态，以及图书馆官方资料入口。

手机检查使用浏览器视口，不等同于实体 iOS/Safari 或 Android 验收。固定舞台采用非滚动裁切，避免手机缩屏或聚焦入口时整张纸被浏览器自动滚出视野；档案和索引仍可单独滚动。没有真人首次使用测试，因此不宣称已经证明新用户无需帮助即可完成探索。

此轮实际页面检查包括 30 组楼层/年代切换、1976/1993 对照往返、1998 已知记录、Escape 返回镜子、档案内阅读位置与焦点恢复、官方资料入口、三楼至蜂蜜公爵的跨卷回归。390×844、320×568、375×812、430×932 视口检查没有水平溢出或工作区自动滚动，对照条没有遮盖画布。
