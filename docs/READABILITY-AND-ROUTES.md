# 手机可读性与空间路线检查

本轮保留旧新闻纸、版画和墨迹动画，不增加光标、音频或其他特效。

## 手机

- 地图上的中文地名按屏幕尺度放大；地图视野外或相互遮挡的标签会避让，地点本身及目录入口不删除。
- 总览时人物使用中文简称；放大到细读尺度后恢复完整中文姓名。姓名文字保持约 12 CSS 像素，切换带阈值缓冲，避免在缩放边界反复跳动。英文及完整中文姓名仍保存在人物 title 中。
- 姓名卷轴避让地名、其他姓名、门口与密道入口；空间不足时暂不显示该卷轴，脚印继续保留。避让范围包含卷轴两侧的飘带。
- 楼层签、地图控制和常用按钮扩大触摸范围；搜索字号为 16px。
- 地点档案使用下半屏面板，上半屏保留地图；关闭按钮固定在档案顶部，内容独立滚动。
- 手机目录关闭时禁用其键盘焦点，增加遮罩和 Escape 关闭；关闭档案后恢复地图位置的焦点。

## 路线

`MAPART.planFor(floor)` 选择楼层图与人物路线的同一坐标来源；`MAPART.floor()` 返回所绘制的 `plan`，界面将它直接交给人物动画。地下、地面层、三楼、四楼、七楼已有独立导览平面，其余五组仍沿用 `MAPART.floorPlan`。人物仅在公共区域内往返：地面层开放门厅和庭院回廊，地下路线绕开房间、水果画和木桶区域，七楼绕开肖像、挂毯、梯口和盲区。不进入沙漏所在区域、中央庭院、礼堂内部或密道，不模拟跨楼层行程。所有布局仍为导览重建，不代表十个真实且精确的霍格沃茨楼层蓝图。

`scripts/check-routes.mjs` 对十个楼层 × 三个年代进行逐单位路径采样，并检查包含左右脚偏移的保守边界是否留在走廊内、是否触及房间。该检查只证明本项目绘图内部一致，不证明原著地理真实性。

四楼镜后通道随新平面从实际镜框位置开始；三楼挂毯捷径的示意线对准陈列廊与魔咒课区域。最新检查核对五个独立楼层的热区中心、关联档案端点和动画使用的平面选择，共 94,815 个路径采样位置。镜后旧路的较早年代标为推定，不证明 1976 年可以通行；1993 已坍塌，1998 未确认修复。七楼的有求必应屋只作札记，1998年肖像通道仍独立处理，详见[七楼说明](SEVENTH-FLOOR.md)。

校域不再采用穿过建筑的旧直线；改为两段对照本项目插画可见小径描出的短路线。校域是透视插画，路线仅经视觉检查，不能像楼层平面一样宣称墙体碰撞已获数学验证。不把视觉小径当成小说确认的路线，也不让人物追踪延伸到霍格莫德。

每份地点档案新增“资料边界”，将作品章节线索与建筑、坐标、比例及动态路线的绘图重建区分开。此次没有新增地点或改写原著事件。

三楼样板的设计依据、两端往返入口与测试范围见 [三楼与关联线索](THIRD-FLOOR.md)。手机展开密道对照时暂时收起标题与楼层签，为图面留出空间；关闭后恢复。对照按钮至少 48px 高，关闭按钮至少 44px，资料边界在短屏上也保留。

四楼的书架、绳索与年代对照见 [四楼说明](FOURTH-FLOOR.md)。固定工作区、地图舞台与画布使用 `overflow: clip`，避免聚焦 SVG 入口或缩小视口时，浏览器把整个隐藏工作区滚到屏幕之外；档案和地点目录仍保留自身滚动。

地面层的公共空间与非行走区分离，见[地面层说明](GROUND-FLOOR.md)。两个楼层索引入口位于图面下缘，手机尺寸下按当前缩放调整文字和命中区，保持至少 44px 高，不覆盖门厅的房间入口。

地下详见[地下层说明](DUNGEONS.md)。楼层索引的触摸规则统一复用；初始视野为短屏预留完整点击区。320×568 下，地面层的两个入口和地下返回入口均完整显示 44px 高度，而非仅有部分矩形留在画布里。切年代也会保留档案当前的打开/收起状态，不重新弹出已经关闭的面板。

### 楼层取景与短屏

楼层初始取景改为读取静态 SVG 绘图边界，不再为每层写固定倍率。重复的图内楼层标题和极小的底注不参与展示；当前楼层仍由楼层签标示，重建边界保留在页眉、札记及地点档案中。绘图四周留少量屏幕边距，有跨层入口时额外保留底部触控空间。

320×568 这类短屏压紧城堡页眉，保留标题、楼层签和工具，绘图区从 101px 增到 191px。复位按钮与键盘 `0` 返回当前层总览。总览随窗口变化重新取景；手动放大或拖动之后保留当前观察位置，不强制跳回全层。

`reading.js` 只负责呈现几何，不改人物路线、落脚位置或年代数据。`check-reading.mjs` 覆盖五种画布比例下的边界、纵横比、底部触控预留与姓名字号，并直接运行应用中的简称/全名更新函数。浏览器另测全部十组楼层；这些是浏览器窗口测试，不是真机测试。
