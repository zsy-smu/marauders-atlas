> **我庄严宣誓，我没干好事。**
>
> 点开一张折起的旧地图，看墨迹在纸上苏醒。沿着黑湖找到城堡，走进三楼的走廊，再从独眼女巫的档案翻到蜂蜜公爵地窖——熟悉的名字，开始连成可以自己发现的故事。

这是一个中文界面的非官方《哈利·波特》互动图册。它把旧新闻纸、铜版式插画、电影式脚印与带出处的地点资料放在一起，让地图既能看，也值得慢慢读。

## 值得停下来看的，不只有城堡

### 墨迹不是浮在背景上的 UI

纸浆纤维、污渍、透印、折痕与参差纸边构成底色；版画和章印通过混合层融进纸面。开图时，墨迹以噪声遮罩显影，而不是简单淡入一张图片。屋瓦、树冠、水纹与街巷，则留给愿意放大细看的人。

### 脚印不是跟着人滑动的尾巴

左右脚按距离交替落下，旧鞋印留在原地，再逐级磨损、消退。姓名跟着示意人物走，已经落下的墨迹不会跟着跑。按下暂停，连旧脚印的消退也一起停住。

### 密道，是两处故事之间的联系

从独眼女巫翻到蜂蜜公爵，再返回三楼；从奖品陈列室附近的挂毯，对照魔咒课走廊另一端。档案和图面使用同一组线索，不必看完一段文字后，再凭记忆重新搜索。

### 年代，不只是一张颜色滤镜

在四楼对照镜后旧路：较早年代显示推定示意，1993—94 显示已知坍塌记录。地图也保留它不知道的事情——没有确证的出口，不随手接到一家商店；有求必应屋的盲区，不用人物动画填满。

## 先从这条线索开始

1. **唤醒地图。** 轻触封面誓词，看墨迹显影。
2. **到三楼找独眼女巫。** 打开档案，选择“翻到蜂蜜公爵 · 地窖线索”，再从另一端返回。
3. **留意那幅挂毯。** 对照奖品陈列室与魔咒课走廊，看看一条捷径如何串起两处地点。
4. **翻到四楼。** 看图书馆的书架与阅览桌，再点“对照年代”，比较镜后旧路的不同记录。
5. **停一下，再收起。** 放大脚印，暂停观察残墨，最后按“恶作剧完毕”。

不需要先读完说明书，也不用按顺序打卡；这只是一条适合第一次探索的路线。

## 手机上，也能把地图读下去

纸面右下角的“目录”负责找地点，下半屏档案负责承接文字。地名与姓名按屏幕尺度调整，对照条为图面让出空间，常用控制保留足够的触摸区域。系统启用“减少动态效果”时，相应动画会关闭。

## 快速开始

有 **Node.js 20+**，三条命令即可预览，**不用执行 `npm install`**：

```sh
git clone https://github.com/zsy-smu/marauders-atlas.git
cd marauders-atlas
npm start
```

打开终端显示的地址，默认是 `http://127.0.0.1:4173`。本地预览不需要账号、API 密钥或后端服务。

没有 Git？也可以[下载源码 ZIP](https://github.com/zsy-smu/marauders-atlas/archive/refs/heads/main.zip)，解压后进入项目目录运行 `npm start`。

已有 Python，也可以直接启动静态服务：

```sh
python -m http.server 4173 --directory dist
```

[托管版本](https://marauders-map-cn.zsiyuan202.chatgpt.site/)受站点访问权限控制，**不作为人人可访问的公开 Demo 承诺**；仓库源码可以独立运行。本次文档更新不会改变站点权限。

### 几个顺手的操作

| 操作 | 用途 |
| --- | --- |
| 点击建筑／地点目录 | 定位并打开档案 |
| `/` | 搜索地点、人物线索或密道 |
| 拖动、滚轮、双指 | 漫游与缩放 |
| `+`、`-`、`0` | 放大、缩小、恢复全图 |
| 暂停／密道／足迹开关 | 选择自己的观看节奏 |
| `Esc` | 收起当前对照、档案或目录；没有面板时收起地图 |

## 好看之外，也把细节做在代码里

- **绘图与行走共用坐标。** 已独立的楼层返回各自平面，人物不会仍沿旧模板走廊穿过新房间。
- **墨迹有自己的生命周期。** 固定鞋印池、交替落脚、八级磨损遮罩；不靠无限新增节点维持动画。
- **交互有返回路径。** 跨卷线索、年代对照、目录、关闭操作与键盘焦点一起考虑。
- **检查有明确范围。** `npm run check` 覆盖脚本、档案、资源、动画与路线；当前含 10 组楼层 × 3 个年代、92,475 个路径采样位置及双脚余量检查。

这些检查证明的是项目内部的一致性，不是原著测绘准确性，也不等于完成了所有实体手机与浏览器的验收。

## 忠于线索，也诚实留白

地点资料以七部小说、官方 HarryPotter.com／J.K. Rowling 资料为优先，Harry Potter Lexicon 作为非官方章节索引辅助；每份档案都带作品线索和可点击资料入口。

- **50 份档案**包含跨分卷关联条目，不是 50 个完全不同的地理实体。
- **10 组楼层**中，三楼、四楼已独立设计，其余八组仍共用导览布局；所有平面均非官方建筑蓝图。
- **三个年代**用于人物组与资料状态，不是完整的历史场景模拟。1976 年的镜后旧路仅为较早年代推定，不证明当年可通行。
- **霍格莫德**是补充地方志，不显示村内人物追踪；人物足迹也不是原著事件的实时回放。
- **插画不是官方扫描。** 两张大幅底图为生成式插画，地名、热区、路线与人物另行绘制。纸纹、素材来源和权利边界均有记录。
